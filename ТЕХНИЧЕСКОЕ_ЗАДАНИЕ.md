## 2. Назначение и цели создания системы

**2.1. Назначение системы**  
Автоматизированная система «CoteboPC» предназначена для удалённого управления и мониторинга персонального компьютера пользователя в режиме реального времени через Telegram-бот.

**2.2. Цели создания системы**  
Создать кроссплатформенное настольное приложение, позволяющее значительно упростить задачи администрирования и повседневного контроля персонального компьютера.

**2.3. Критерии достижения целей**  
- Все заявленные функции версии 1.0 работают стабильно на Windows 10/11 (64-разрядная) и Fedora (версия 40 и выше);  
- Время отклика на команду из Telegram — не более 3 секунд;  
- Приложение запускается и подключается к боту за один клик (мастер настройки при первом запуске).

## 3. Характеристика объектов автоматизации

**3.1. Основные сведения об объекте автоматизации**  
Объект автоматизации — персональный компьютер пользователя.

**3.2. Требования к объекту автоматизации**  
- Операционная система: Windows 10/11 (64-разрядная) или Fedora (версия 40 и выше);  
- Установленный .NET 10.0 Desktop Runtime;  
- Доступ в интернет (для связи с Telegram Bot API).

**3.3. Условия эксплуатации**  
Приложение работает в фоновом режиме после первого успешного запуска и авторизации. Пользователь — один человек с базовыми навыками работы с ПК и Telegram.

## 4. Требования к системе

**4.1. Требования к структуре и функционированию системы**  
В состав системы входят:  
- Подсистема «Клиент» (настольное приложение CoteboPC);  
- Подсистема «Бот-интерфейс» (Telegram-бот).

Взаимодействие компонентов осуществляется исключительно через Telegram Bot API (long polling) в формате JSON.

**4.2. Требования к функциям (задачам), выполняемым системой**  

Перечень функций версии 1.0:

1. Графический интерфейс мастера настройки токена бота при первом запуске.  
2. Подключение и сохранение токена бота локально.  
3. Отправка скриншота текущего экрана.  
4. Управление медиаплеером (Play/Pause, Next/Prev, Volume).  
5. Вывод системной информации (CPU, RAM, Disk, IP-адрес, uptime).  
6. Управление мышью (клик ЛКМ/ПКМ, перемещение, скролл).  
7. Отображение диалоговых уведомлений на ПК.  
8. Загрузка/выгрузка файлов между ПК и чатом Telegram.  
9. Скачивание файла по прямой ссылке.  
10. Открытие ссылки в браузере.  
11. Выключение / перезагрузка / спящий режим ПК.  
12. Выполнение произвольных консольных команд с выводом результата.  
13. Включение/выключение Bluetooth.  
14. Вставка текста из бота в активное окно.  
15. Скрытие (минимизация) всех окон.  
16. Переключение и создание рабочих столов (виртуальных десктопов).  
17. Управление презентацией (следующий/предыдущий слайд, начало/окончание).

Для каждой функции результат должен поступать в чат Telegram в течение 3 секунд.

**4.3. Требования к видам обеспечения**

**4.3.1. Программное обеспечение**  
- Основной язык: C# (.NET 10).  
- Кроссплатформенный UI: Avalonia UI.  
- Работа с Telegram: Telegram.Bot.  
- Другие open-source NuGet-пакеты.

**4.3.2. Техническое обеспечение**  
Минимальные требования: 4 ГБ ОЗУ, 100 МБ свободного места на диске.

**4.4. Общие технические требования**

- **Надёжность**: Работа без сбоев не менее 24 часов. Автоматический перезапуск (watchdog). Автозагрузка при старте ОС.  
- **Безопасность**: Токен хранится зашифрованным. Все операции локальные.  
- **Эргономика**: Минималистичный интерфейс с поддержкой тёмной/светлой темы, работа в системном трее.  
- **Режимы работы**: «Подключён», автозагрузка, фоновый режим.
